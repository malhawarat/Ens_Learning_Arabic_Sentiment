# Note on model checkpoints

Trained RAAF module checkpoints (`raaf_model_seed*.pt`) are not included in this
directory, consistent with the manuscript's Data Availability statement: model
checkpoints are binary artefacts rather than language resources and are available
from the corresponding author on reasonable request, rather than redistributed here.
